# Bambu Lab A1 Mini — Pen Plotter Engine

Комплексное решение (генератор машинного кода и 3D-геометрии) для переоборудования 3D-принтера **Bambu Lab A1 mini** в высокоточный перьевой плоттер. Программа предназначена для автоматического рукописного заполнения тетрадей (в клетку, линейку или чистых листов), написания лекций, шпаргалок, конспектов и отрисовки таблиц.

Приложение разработано без сторонних внешних библиотек (Zero External Dependencies) и функционирует исключительно на стандартной библиотеке Python 3 и системном WinAPI GDI32.

---

## Архитектура и функциональные возможности

### 1. Обработка шрифтов и рендеринг глифов
* **Встроенный скелетный шрифт (Single-stroke / Stick Font):** 
  Специально оптимизированный однолинейный алфавит (кириллица, латиница, цифры, базовая пунктуация). В отличие от типовых шрифтов формата TrueType, которые плоттер обводит по внешнему замкнутому контуру, скелетный шрифт вычерчивает каждый символ строго **в один проход** пера.
* **Векторизация шрифтов через Windows GDI32 (`GetGlyphOutlineW`):**
  Инструмент прямого чтения векторных данных из любых файлов `.ttf` и `.otf` без использования сторонних парсеров (`fonttools` или `freetype-py`). Поддерживается конвертация квадратичных сплайнов Безье (`TT_PRIM_QSPLINE`) в полилинии штрихов на лету.
* **Модуль имитации почерка (Humanizer):**
  Вводит случайные микроколебания базовой линии строки, легкую вариативность наклона символов и высоты глифов для устранения визуального эффекта машинной печати.

### 2. Кинематика и компенсация смещения инструмента (Offset 33.5 мм)
При установке кронштейна для ручки на каретку печатающей головки стержень оказывается физически смещен относительно сопла хотэнда (по умолчанию задано плечо **33.5 мм**).
* **Программный расчет зоны безопасности (`_get_safe_bounds`):** 
  Границы рабочего поля стола 180×180 мм динамически корректируются с учетом выбранного направления смещения (спереди, сзади, слева, справа), исключая риск механического удара каретки об ограничители стола.
* **Пересчет координат:** 
  Траектории перемещения сопла смещаются в противофазе координатам кончика пера:
  $$X_{\text{nozzle}} = X_{\text{pen}} - \Delta X, \quad Y_{\text{nozzle}} = Y_{\text{pen}} - \Delta Y$$

### 3. Парсер таблиц Markdown
* Распознавание стандартного табличного синтаксиса Markdown (`| Колонка 1 | Колонка 2 |`).
* Автоматический расчет пропорциональной ширины столбцов под ширину текстовой зоны.
* Автоматический перенос строк внутри ячеек и физическая прорисовка границ таблицы ручкой.
* Автоматическая пагинация: при переполнении листа контент переносится на следующую страницу с соблюдением отступов.

### 4. Вертикальный отрыв инструмента (Z-Hop)
* При холостых переездах (`Travel`) ручка принудительно поднимается на безопасную высоту (по умолчанию $Z = 5.0\text{ мм}$).
* Опускание на высоту контакта с бумагой ($Z = 0.20\text{ мм}$) и отрыв происходят строго вертикально в граничных точках штриха, предотвращая появление чернильных полос и помарок при ускорениях.

## Режимы экспорта

1. **Автономный G-code (`.gcode`):**
   * Генерирует готовый управляющий файл для прямой печати.
   * Аппаратные блокировки безопасности: полное отключение нагревателей сопла и стола (`M104 S0`, `M140 S0`), отключение обдува (`M106 S0`) и датчика окончания филамента (`M412 S0`).
   * Встроена калибровочная пауза (`M400 U1`) в центре стола для выставления высоты пера.
2. **Патчер нарезанных файлов Bambu Studio (`.gcode.3mf` / `.gcode`):**
   * Распаковывает архив проекта слайсера, анализирует `Metadata/plate_1.gcode`, вырезает команды нагрева и внедряет подъем оси Z перед каждой командой холостого хода `G0`, обновляя контрольную сумму в `.gcode.md5`.
3. **Объемные 3D-модели (`.3mf` / `.stl`):**
   * Преобразует двумерные векторные траектории в объемные призматические сетки толщиной в один слой ($0.20\text{ мм}$, ширина линии $0.44\text{ мм}$) для нарезки в сторонних слайсерах (Bambu Studio, OrcaSlicer, PrusaSlicer).

## Горячие клавиши и управление предпросмотром

| Действие | Назначение |
| :--- | :--- |
| **ЛКМ (Перетаскивание)** | Физическое перемещение текста и таблиц по поверхности листа (в миллиметрах стола). |
| **Колесико мыши** | Масштабирование контента (30% – 250%). Изменяет итоговый масштаб при экспорте. |
| **ПКМ (Перетаскивание)** | Панорамирование камеры холста. |
| **Ctrl + Колесико мыши** | Оптический зум предпросмотра (лупа). |
| **Сброс поз.** | Возврат положения текста в координаты по умолчанию. |
| **Вид 100%** | Центрирование стола и сброс масштаба камеры. |

## Установка и запуск

### Требования
* Операционная система: **Windows 10 / 11** (подсистема WinAPI необходима для функции извлечения внешних шрифтов).
* Интерпретатор: **Python 3.8+**.

### Запуск
```bash
# Клонирование репозитория
git clone https://github.com/kifil228/Plotter-for-bambulab-A1-mini-.git
cd Plotter-for-bambulab-A1-mini-

# Запуск приложения (сторонние пакеты через pip устанавливать не нужно)
python plotter.py
```

## Регламент настройки станка перед печатью

### 1. Механическая фиксация
1. Закрепите лист бумаги на печатной пластине (PEI) малярным скотчем по углам или периметру.
2. Установите кронштейн держателя ручки на печатающую головку. Рекомендуется использовать адаптеры с подпружиненным ходом стержня ($1.5 - 3.0\text{ мм}$) для сглаживания локальных неровностей стола.

### 2. Юстировка нуля по оси Z
При печати автономного `.gcode`:
1. Принтер выполнит базовый автодом (`G28`), поднимет инструмент и переместится в центр стола (`X90 Y90`).
2. Сработает команда безусловной паузы `M400 U1`.
3. Ослабьте винт крепления ручки, опустите пишущий узел до легкого контакта с листом бумаги (сжав компенсирующую пружину держателя примерно на $0.5 - 1.0\text{ мм}$) и затяните зажим.
4. Нажмите **Resume** на сенсорном экране принтера или в приложении Bambu Handy.

### 3. Ручной слайсинг в Bambu Studio (при экспорте моделей .3MF / .STL)
Если нарезка производится вручную в слайсере, в настройках принтера задайте следующие параметры:
* **Printer settings → Extruder → Z hop when retract:** `5.0 mm`
* **Printer settings → Extruder → Z hop type:** `Normal`
* **Printer settings → Extruder → Travel distance threshold:** `0.1 mm`
* **Filament settings → Temperature:** `0 °C` (сопло и стол для всех слоев)
* **Print settings → Quality → Layer height:** `0.20 mm`
